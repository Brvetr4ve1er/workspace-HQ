## Dish 3: The Vault desk (size M)

**Owner gets.** In Life, Notes tab: today's daily note read-only (plain text, secrets masked, 20 KB cap), one capture line that appends a single line to today's note on Enter, the twelve most recent notes (names only), and "Open in Obsidian". No graph, no markdown rendering, no creating notes.

**Files, new.** `dashboard/vault-desk-core.mjs` (pure: date tokens, path checks, line normalizer, append planner, recent sorter), `dashboard/vault-desk.js`, `tools/vault-desk-fixture-paste.mjs`, `dashboard-v5/src/{logic,vals,tpl,live}/vault-desk*`.

**Files, touch.** `main.js`, `preload.js`, `fake-preload.js`, the Life Notes tpl branch, `dashboard/use-log.js` (its two surfaces).

**Vault.** When `HQ_VAULT_DIR` is set it is the only vault; a missing folder returns "vault not found" and never falls back to the default vault. Folder and date format come from the vault's `.obsidian/daily-notes.json`, treated as untrusted input; with none, the app's own daily folder name is used and the card says in words which folder it looks in.

**Path safety.** Reuse `safeSegment` from `claude-vault.js`. Reject absolute paths, drive letters, `..`, `:` and trailing dots or spaces; the name must end in `.md`. Resolve the parent with realpath and require it inside the vault's realpath. Never create folders or files: a missing parent or a missing note makes the card say so in words and nothing is written. Lstat the target and refuse a symlink or reparse point before append.

**Capture rules.** The planner always writes `- ` plus the line, collapses control characters, breaks any `wq:` token anywhere in the line (for example `wq :`), and escapes a leading `[` or `>` so a capture can never read as a ticked checkbox for `dashboard/daily-notes-watch.js` `tickedIds`. Appends only at end of file with `fs.open(file,'a')`, a newline first if missing, below any `%% workspacehq %%` block; a "Captured" heading is added only if the last heading is not Captured. Re-entrancy lock; 30 captures an hour. Reads are masked. Text is verbatim except control characters collapsed and `wq:` neutralized.

**Open in Obsidian.** The vault name is the folder basename; Open appears only when it is in the inventory (`vault-open.js` rule). `vault-desk.js` takes an injected `vaultOpen`.

**IPC.** `hq:vault-desk:read` and `hq:vault-desk:capture`. Main window only, sender check, the `safe()` pattern from `claude-vault.js` lines 240-241 but returning codes, never `e.message` or paths.

**Structure-lane ask (HANDOFF, not code here).** `collector/assemble.mjs` rewrites the whole note by read-then-write, so a capture between its read and write is lost; ask for a recheck before write. Until then a test pins that a nightly rewrite after a capture keeps the captured line.

**Vals key.** `vdkv` (986 to 987).

**Tests.** `node --test dashboard/vault-desk-core.test.mjs dashboard/vault-desk.test.mjs` on a temp vault, each asserting nothing was written outside the temp folder: missing note; no trailing newline; `format` of `../x` and `a:b`; missing parent folder; a junction as the note file and a 5,000-character line; planted secret masked on read; `HQ_VAULT_DIR` set but missing returns "vault not found" with no fallback; `[x] done wq:id` capture run through `tickedIds` returns no ids; foreign sender refused; rate limit.
