## Global Constraints (binding on every agent)

- **Additive-only.** No `latest.json` shape change. IPC additive-only, `docs/sync/IPC-CONTRACT.md` rows BEFORE handlers. `dashboard/claude-sessions.js` READ-ONLY (its `start({args, onOutput})` is the seam).
- **The user's app is LIVE on v4 right now. NEVER kill or relaunch it.** All verification through the dev harness (`dashboard-v4/dev-main.js`) and offscreen throwaway harnesses only.
- **COMMIT RULE (a parallel-fleet race bit the last run twice):** stage AND commit by explicit pathspec — `git commit -m "..." -- <your paths>` — never a bare `git commit`. Never `git add -A`. Never touch `data/quest-overrides.json` or `data/.ui-version`.
- **Selftest gates:** v4 `dashboard/node_modules/electron/dist/electron.exe dashboard-v4/dev-main.js --smoke --selftest` → `V4 SELFTEST surfaces=6 errors=0 PASS`; v3 regression `... dashboard-v3/dev-main.js --smoke --selftest` → `SELFTEST combos=105 errors=0 PASS`. Run tests by FILE, never a bare directory.
- **XSS:** every scan/session-derived value into `innerHTML` through `esc()`; raw session output via `textContent` only. **Lifecycle:** everything created on mount torn down in `unmount()` and before re-render; handlers by property assignment; surfaces mount/unmount 6× per selftest and re-mount on `data:select` (see S6 scrubber note).
- **No dead or lying controls.** Real action, or disabled-with-reason (`title`). Async effects say so. The capture reload hazard (`hq:capture-save` → spawnSync + win.reload) still stands — never promise a post-capture confirmation.
- **View contract** (identical to `surfaces/work/view.js` — read it first): `export const view = { mount(root, ctx), unmount() }` with `ctx = { data, bus, hq }`. Surfaces S1–S5 do NOT touch `boot.js`/`shell.js` — S6 swaps all registrations at once (this is what prevents a 5-way merge collision on the shell).
- **Source material:** the v3 realm views are the feature truth — port their CONTENT into the v4 idiom (System-HUD tokens `--hud-*`, the v4 one-item/card language from `styles/components.css`, plain copy, no lexicon). Do not copy v3 markup wholesale; rebuild it on v4 components. Feature parity is the bar: nothing v3 showed may be silently dropped — if something cannot land, say so in the report.
