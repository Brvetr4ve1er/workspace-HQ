# WorkspaceHQ v4.0 — THE SPINE — Implementation Plan

> Executes the approved design `docs/superpowers/specs/2026-08-03-workspacehq-v4-harness-design.md`.
> Fleet-executed (phased workflow, strict file ownership, review gates). Steps carry exact
> interfaces; implementers read host code before editing.

**Goal:** Close the loop. Dispatch an agent at a real project from inside the app, watch it stream, kill or let it finish, see what it changed — no terminal.

**Tech:** Electron 32, vanilla ESM over `file://`, no build step, CSP `default-src 'self'`. Tests: `node --test` (FILES only, never bare directories). New renderer in `dashboard-v4/`, selected by `data/.ui-version` = `"v4"`; v3 is the rollback.

## Global Constraints

- **Additive-only.** `latest.json` untouched. New IPC rows announced in `docs/sync/IPC-CONTRACT.md` BEFORE handlers. Main-process logic in NEW file `dashboard/session-api.js`; `dashboard/main.js` gets ONLY (a) the v4 branch in the `.ui-version` loader ternary and (b) one `require('./session-api')` hook line. `dashboard/preload.js` gets one minimal additive block. `dashboard/claude-sessions.js` is **NOT modified** — its `start({ onOutput })` callback is the seam.
- **No dead or lying controls.** Real action, or disabled-with-reason. Async effects state their asynchrony.
- **XSS:** every scan/session-derived value into `innerHTML` goes through `esc()`. Session output is untrusted text — always `textContent` or `esc()`.
- **Security:** `session-api.js` containment-checks `cwd` under the same `DOCS_ROOT` rule as `resolveProjectPath` (re-implemented locally, main.js not edited for it); task capped at 2,000 chars; no `shell:true`.
- **Substrate copied unchanged** from v3: `intel/derive.mjs`, `intel/foresight.mjs`, `intel/agency.mjs`, `core/actions.mjs`, `core/notify.mjs` + their tests.
- One theme. No lexicon. Plain copy.

**Verified seams (do not re-derive):**
- `dashboard/claude-sessions.js`: `start({label, args=['-p'], input, cwd, timeoutMs, onOutput, onDone, command}) → {jobId}|{error}`; `list()`, `kill(jobId)`, `setOnChange(fn)`; sessions push already flows renderer-ward as `hq:claude-sessions` (main.js:973). Default `args:['-p']` = **print mode** — headless, exits on completion.
- `.ui-version` loader: `main.js:139-150` (`uiVersion()` + ternary choosing `dashboard-v3/index.html`).
- v3 dev harness pattern to mirror: `dashboard-v3/dev-main.js` (`--smoke`/`--selftest`, scratch userData, `HQ_V3_PRELOAD=v2` loads the real preload).
- Renderer data: `index.html` loads `../dashboard/data.js` (window.DATA), then ESM boot.
- Visual seed: `dashboard-v3/styles/realms/warroom.css` — the System-HUD language (violet neon `#a78bfa` family on near-black, hexagon-cut frames, scanlines, glow), now app-wide and refined. Vendor `anime.es.js` (copy from v3 vendor/); NO three.js in the spine.
- Live pushes that already exist: `onClaudeSessions`, `onMachine`, `onBrowserTab` (+ `getSessions()`, `getBrowserLive()`).

### Phase B — three parallel agents, disjoint files

**B1 · `src/intel/queue.mjs` + test (pure).** May import pure siblings (`derive.mjs`, `agency.mjs`) — they are import-free themselves; no DOM/Date.now/globals.
`buildQueue(selected) → { items, counts }` where each item is
`{ id, source:'threat'|'task'|'gap'|'idea', title, detail, projectId, projectName, projectPath, severity:'red'|'orange'|'yellow'|'dim', verbs:[...] }`.
Sources & verbs: `triage(selected)` → threats, severity via warroom's kind map, verbs `['dispatch','open']`; open quests (`status==='open'||'in_progress'`) → tasks, severity by tier, verbs `['done','dispatch','open']`; `agencyProposals(selected)` → gaps, severity `'dim'`, verbs `['dispatch','note']`, carrying `seedPrompt`; `side_quests` with `kind==='idea'` → ideas, severity `'dim'`, verbs `['dispatch']` (title becomes the task). Order: threats (blast desc) → tasks (tier) → gaps → ideas. `projectPath` resolved from `selected.projects` by id; items without a resolvable path DROP `'dispatch'` from verbs (never an inert verb). `counts` = per-source totals. Never throws on null/{} → `{items:[],counts:{}}`. TDD; concrete assertions.

**B2 · `src/state/live.js` + testable core.** One boot-time subscriber for the live pushes: holds `{ sessions:[], machine:null, browser:null }`, exposes `get()`, `on(fn)→off`, `initLive(hq)` (guards missing methods). Pure reducer split into `src/state/live-core.mjs` (`applyEvent(state, evt)`) with `node --test`; the DOM/hq wiring stays thin in `live.js`. Also `onSessionOutput` ring buffer per jobId (cap 64KB) with `getOutput(jobId)`.

**B3 · session IPC.** ORDER: (1) rows in `docs/sync/IPC-CONTRACT.md` (Pending→table): `hq:session-start {cwd,task,label}→{jobId}|{error}`, `hq:session-kill jobId→bool`, `hq:session-diff {cwd}→{files:[{path,status}],stat}|{error}`, push `hq:session-output {jobId,chunk}`. (2) NEW `dashboard/session-api.js`: exports `init({ipcMain, claudeSessions, send})`; handlers wrap `claudeSessions.start` (cwd containment-checked under DOCS_ROOT — local re-implementation; task cap 2000; label default from task), `kill`, and a git probe (`spawnSync('git',['status','--porcelain'],{cwd})` + `['diff','--stat']`, no shell). `onOutput` → `send('hq:session-output',{jobId,chunk})`. (3) ONE hook line in `main.js` near line 973 (`require('./session-api').init({ipcMain, claudeSessions, send:castSend})` — read main.js first; `castSend` is the existing renderer-push helper; adapt to what's actually there). (4) Additive preload block: `sessionStart`, `sessionKill`, `sessionDiff`, `onSessionOutput`. `node --check` main/preload/session-api; v3 selftest must stay green.

### Phase C — WORK surface + System-HUD core (1 agent, opus)
**Owns:** `dashboard-v4/src/surfaces/work/**`, `dashboard-v4/styles/{work.css,components.css}`, registration touch in `boot.js/shell.js`.
Three-column workbench, `1440×900` primary: **left QUEUE rail** — ONE item component rendering `buildQueue` items grouped by source with counts; verbs as real buttons (`dispatch` → fills the agent pane's form; `open` → project drawer-lite (name/path/health from scan); `done` → `hq.markQuestDone` guarded; `note` → `capture:note` action with the Epic-C honest-async pattern). **Center AGENT pane** — dispatch form (target = project select from scan; task textarea, prefilled by `dispatch` verbs); running sessions as cards (label, status, elapsed); selecting one shows **live streaming output** (from B2's ring buffer + `onSessionOutput`), auto-scroll w/ stick-to-bottom, KILL button (`sessionKill`), and on completion a **CHANGES panel** (`sessionDiff(cwd)` → files + stat, honest empty state "no changes detected"). **Right TRUTH rail** — live machine vitals, active browser tab, session presence (from B2 state), each with a "live/stale" indicator; scan date shown as "snapshot" explicitly. All dynamic text `esc()`'d or `textContent`. Every control real or disabled-with-reason (dev harness: no `window.hq` → dispatch form disabled with explanation). Motion: anime.js ONLY on real state changes (session start slide-in, output pulse, session done sweep, item cleared). System-HUD: violet-on-near-black, hexagon-cut panel frames, glow edges, display-scale numerals; typographic scale ≥ 5 steps. `prefers-reduced-motion` honored. Selftest stays PASS.

### Phase D — Verify + adversarial review (2 agents, then ≤1 fix round)
**D1 verify:** all v4 unit tests by file; v4 selftest; v3 selftest (regression); real-preload run (`HQ_V4_PRELOAD=v2`): confirm queue renders from live data (counts vs Node-computed ground truth), controls enabled, then **one real end-to-end session**: create scratch dir inside `Documents/` (`hq-v4-e2e-scratch`, git init), `sessionStart({cwd, task:'Reply with exactly READY and stop.'})` (print-mode claude), assert output streams and status settles, then `sessionDiff` returns cleanly; delete scratch. Offscreen screenshots of WORK (queue populated + a session card) → `dashboard-v4/tools/shots/`. **D2 review (opus):** whole-diff adversarial review vs this plan's constraints (esc coverage, lifecycle/teardown incl. `onSessionOutput` unsubscribes, containment check correctness, lying-control hunt, IPC-doc-before-code). Findings → one fix agent → scoped re-review.

**Exit gate:** D1 all green incl. the real session e2e; D2 clean or fixed; HANDOFF.md entry appended (`fe:`/`meta:` commits throughout; never `git add -A`; never touch `data/quest-overrides.json`).
