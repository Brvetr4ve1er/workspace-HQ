### Spec

VERIFIED ANCHORS. dashboard/brief-project.mjs exports projectBrief(brief, { now, firstSeen }) (PURE, ESM): items {ref, rule, severity, sevWord, text, count, ...} built from the fixed WORDING table (never the item's own text), overflowLine, more, stale and ageMinutes (STALE_MIN = 30; ageMinutes null when there is no timestamp), standing; it returns null for a non-object. data/brief.json is written by dashboard/brief.js (gitignored; its raw items carry names and paths, so the tool must never print raw fields). Output, every line from the projection only: up to three item lines '<sevWord>: <text>' (sevWord urgent / soon / when you can; text is the WORDING row with its {n}), then ONE overflow line when more > 0 (the projection's overflowLine). The process ALWAYS exits 0 (a SessionStart hook must never block): every failure path prints its one line, including an uncaught error (top-level try/catch). Total output under 600 characters.
