Date 2026-11-14. Lane: frontend (every shared edit is announced in docs/sync/HANDOFF.md). Source: docs/superpowers/plans/2026-11-14-next-level-plan.md, the "Batch 7 - One Home, less app, and the console layer" table, with all four console parts approved by the owner. Started from main @ 2527f5a.

## Why

WorkspaceHQ says what needs the owner, where they are, then lets them act in place. Batch 7 makes Home that sentence (the Brief on top, ONE next action, everything else folded behind one remembered "more"), takes weight out of the app without deleting anything (reversible folds driven by the use report, proven-dead code removed, every other deletion left as a list for the owner's yes), and adds an opt-in console-era layer (a Console skin, a cartridge shelf for projects, a read-only memory card, a cheat-code registry, a once-per-version card, and a few quiet delights). Everything in the console layer is original SVG and CSS drawn in code, sits behind one master switch that defaults OFF, honours reduced motion, and costs nothing (no stylesheet, timers, frames or DOM nodes; only the one legacy keydown listener that exists today) while off. The freeze rule stays: no new space, no new MCP tool; new views live inside existing spaces or Settings.
